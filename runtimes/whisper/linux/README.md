# Linux x64 Whisper b5130 GPU r1

Two native builds of pinned Whisper b5130: CUDA 12.8.1 (75-real, 89-real, 75-virtual) and Vulkan. No models or drivers are distributed. Vulkan requires the host loader/ICD; CUDA requires a compatible NVIDIA driver. CPU tools remain separate. This revision does not change Windows/macOS assets.

The physical GPU acceptance used Ubuntu 26.04, NVIDIA RTX 4080 / 595.99.02 and Intel UHD 770. Both backends executed Kotoba Q5_0 synthetic probes; CUDA and Intel Vulkan also exercised the Silero v6.2 VAD interface. See release.json for the exact evidence boundary. CI verifies the exact uploaded candidate bytes, source pins and ELF inventories; it does not claim physical GPU inference or that local compilation happened in Actions.

Build entry: `node scripts/build-linux-whisper.mjs <cuda|vulkan> <source-directory> <new-build-directory>`. Place the verified source archive next to the clean extracted source directory. Set CC/CXX to GCC 11.4 wrappers using the Ubuntu 22.04 sysroot; set JAVDEX_CMAKE (3.31.6), JAVDEX_NINJA and JAVDEX_BUILD_JOBS. The wrappers must prioritize sysroot libm/libstdc++ rather than resolve absolute host library aliases. Use the pinned CUDA redistributions to set CUDAToolkit_ROOT; Vulkan needs Vulkan_INCLUDE_DIR, Vulkan_LIBRARY, Vulkan_GLSLC_EXECUTABLE (glslc 2026.1), SPIRV_HEADERS_INCLUDE. Vulkan headers are 1.4.310. No command installs host packages.

Package entry: `node scripts/package-linux-whisper.mjs <cuda|vulkan> <build> <CUDA-library-directory|-> <new-output>`. Set JAVDEX_PATCHELF and the matching JAVDEX_CUDA_LICENSE / JAVDEX_VULKAN_LICENSE. The packager verifies source hashes, configured backend, CPU baseline, native dependencies and glibc <= 2.38, and preserves source/build inventories and third-party licenses. Host driver dependencies are explicit, never replaced with private driver stubs. These pins do not promise byte-for-byte reproducibility.

Immutable release: whisper-b5130-linux-gpu-r1. A local native build is admitted only after the exact candidate has passed physical inference and application installer checks, with both artifacts plus source materials pinned in assets.lock.json. The read-only Linux workflow verifies the uploaded Draft against the exact recipe commit. The finalizer checks all jobs, immutability, commit, attachment identities and tag again before publication. Existing publication gates and all older releases remain unchanged.
